This directory records a simulator diagnostic that attaches an issuing PC to each traced D-cache side-buffer removal. It checks whether the added PC follows the exact load instruction through the D-cache TL and TV stages. The simulator gates pass; routed FPGA fit, Linux attribution, and retirement correlation remain unverified.

The diagnostic carries the backend reservation PC beside the D-cache request without changing the request packet or side-buffer datapath. A TV-stage consume captures a 64-bit metadata word with valid, physical-thread ID, and virtual PC; non-consume removals capture zero. For the tested two-slot Sv39 configuration, bit 40 is valid, bit 39 is the physical thread ID, and bits 38:0 are the PC. I-history slots 232–247 hold metadata indexed identically to D-history removal slots 232–247, while I-history slots 248–255 retain publication records. Same-cycle publication/removal sets the existing preview overflow flag, so a conflicting transcript is rejected.
