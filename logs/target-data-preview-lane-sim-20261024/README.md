The newly added preview port is tied low in the full-core wrapper; this run checks non-preview regression and elaboration, while the standalone UCE gate checks queue behavior.

- First complete guest run: 12 preview rows, `[BSG-PASS] context preview oracle handoff and data`, `CORE PASS`, and `BSG PASS`, followed by simulator status 134. The `bsg_nonsynth_dpi_gpio.sv` final-block assertion reports that `fini()` had not been called. `testing/check_run.py` deliberately accepts this documented post-PASS shutdown exception, but this work treats the host run as unqualified.
- Confirmed cause: `cosim/include/verilator/bsg_zynq_pl.h` called `tb->final()` in its derived destructor before the base class's AXI wrappers were destroyed. Each wrapper's DPI GPIO destructor calls `bsg_dpi_fini()`, so the Verilated final blocks saw live endpoints. The fix clears outstanding coroutines and destroys AXI wrappers before `tb->final()`.
