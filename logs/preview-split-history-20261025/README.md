This directory records the split preview-history experiment. It ties the physical recorder collision to a small RTL change, its simulator controls, and the matching Linux image prepared for a routed FPGA check.

The prior timing-qualified diagnostic physically booted Linux twice but its strict 48-trial removal parser rejected both runs for publication/removal overflow. In run 3 trial 4, the publication count advanced to four while only its first slot held a new cycle; the other three retained the previous trial's cycles, and removal events occupied the publication interval. The benchmark recorded no D-demand misses in that trial. The existing RTL gave D-removal writes priority over simultaneous publication writes to the same BRAM, so this is a confirmed one-port recorder loss rather than a target-address prediction failure.
