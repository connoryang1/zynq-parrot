# Build failures and limits

The first fresh minimal and full-model builds stopped before simulation because the isolated worktree lacked `riscv/bp-tests/bootrom.none.riscv` and `riscv/bootrom/bootrom.none.riscv`. Both were seeded from the prior known-good data worktree at SHA-256 `350ff98649e2b074457162339e9bba6a923719f297cc6f5308365f54c6088607`, and each failed build was cleaned before retry. A later full-model C++ compile rejected the instruction branch's optional processor-state reporter because it names the minimal-core Verilator hierarchy. The reporter now skips that hierarchy in full-system builds, keyed by `GP1_ENABLE`; the failed build was cleaned before rerunning. None of these failed attempts produced a guest result.

The first isolated joint-kernel `vmlinux` link attempt stopped at `/rootfs.cpio`: its existing `.config` sets `CONFIG_INITRAMFS_SOURCE="${BR_BINARIES_DIR}/rootfs.cpio"`, and `BR_BINARIES_DIR` was unset outside Buildroot. The retry supplied `BR_BINARIES_DIR=/home/coyang/zynq-parrot/import/black-parrot-sdk/linux/work/buildroot/images` explicitly; that rootfs has SHA-256 `fedf060d15455f6ad8173999d60b92876d87993405aa9ebb7ae569a18ae282d8`. The retry compiled through much of the kernel but stopped in unrelated SCSI and ATA objects when the host root filesystem filled and GCC could not write temporary assembly files under `/tmp`. The build exited nonzero, so there is no joint `vmlinux` link result. The merged scheduler object alone built and its disassembly contains both CSR hooks. Before another full link, verify free root space and set a spacious task-local `TMPDIR`; never infer a kernel link pass from this failed run.

The merged FPGA area and timing are unmeasured. The instruction branch's prior detached-buffer route fit but missed setup timing by 0.284 ns; its registered repair passed simulation before this merge but has not routed. The data branch's measured Linux four-load saving was -9 cycles with a 95% interval spanning zero. Joint Linux boot and scheduling, L2 residency after the switch, and application throughput remain open.
