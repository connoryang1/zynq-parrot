This directory records the first combined simulation checkpoint for Linux physical data preview and detached instruction replay. It keeps the instruction, physical data, and no-hint control transcripts in separate subdirectories with their exact NBFs and waveforms. These are functional simulations of the merged RTL; no combined FPGA route, Linux boot, or speedup is claimed.

# Integration scope

The top-level merge parents are data branch `a1bb92cb` and instruction branch `d14baa56`; the merged BlackParrot submodule is `1556ce4a53852129ae8fa45741dde2edd92c0029`, merging physical data preview `be1967914a4e9659067e96d505d14ec38631b090` and instruction replay `70829002fadb32524fff4c284a27d5f6b9aa5f4b`. # Build failures and limits

The first fresh minimal and full-model builds stopped before simulation because the isolated worktree lacked `riscv/bp-tests/bootrom.none.riscv` and `riscv/bootrom/bootrom.none.riscv`. Both were seeded from the prior known-good data worktree at SHA-256 `350ff98649e2b074457162339e9bba6a923719f297cc6f5308365f54c6088607`, and each failed build was cleaned before retry. A later full-model C++ compile rejected the instruction branch's optional processor-state reporter because it names the minimal-core Verilator hierarchy. The reporter now skips that hierarchy in full-system builds, keyed by `GP1_ENABLE`; the failed build was cleaned before rerunning. None of these failed attempts produced a guest result.

The merged FPGA area and timing are unmeasured. The instruction branch's prior detached-buffer route fit but missed setup timing by 0.284 ns; its registered repair passed simulation before this merge but has not routed. The data branch's measured Linux four-load saving was -9 cycles with a 95% interval spanning zero. Joint Linux scheduling, kernel patch composition, L2 residency after the switch, and application throughput remain open.
