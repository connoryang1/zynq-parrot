This tool audits HP0 request/response timing and response-stream integrity in a closed whole-core FST. It uses the existing selected FSTAPI reader directly and executes no model or target. All cycle counts describe the observed simulator AXI clock, with no physical calibration or application projection.

```sh
python3 testing/rtl/hp0-closed-trace/run.py --fst CLOSED.fst.xz --model-source-list ACTUAL_SOURCE_LIST.json.gz --log COMPLETED.log.gz --exit-code 134 --delay 200 --proof INDEPENDENT_ADVISORY_PROOF.json --out FRESH_DIRECTORY
```

For native08, supply `--delay 0 --source-ref 40be2ee13ac6d70eed9d222f1465f9b3e571c45d` to recover its exact old compiled top source. Recovery from a Git ref is accepted only when bytes and SHA match the actual consumed-source list. Current exact files and recovered objects are copied into the evidence directory. The optional independent proof must be accepted and bind the same raw FST SHA/size. The maintained terminal checker validates completed CORE/HOST PASS and the actual exit policy.

The auditor observes external `top_fpga_inst.hp0_axi_*` and BP-facing `blackparrot.m_axi_*` pins. It samples stable values before each rising AXI clock edge after observing actual asserted AXI reset. Reset flush is explicit and discarded ownership is recorded. It checks valid/payload hold through stalls, per-ID AR/R and AW/W/B FIFO ownership, RLAST/WLAST versus length, complete eight-byte beat traffic, and zero response errors. W may precede AW; different RIDs may complete out of order. Same-ID association follows the AXI FIFO contract; identical same-ID data swaps cannot be identified without an external-memory content oracle.

For N0, valid, ready and every valid response payload field must match in the same cycle. For N>0, every externally accepted opaque R73/B8 payload must appear downstream once in the same stream order. Its earliest output offer must be `max(input_accept+N,previous_head_accept+1)`, independent of downstream READY; output acceptance may be later under stalls. Actual queue occupancy, full flags, full-input stall counters and the static delay/cycle counter are checked. Stream spacing, request concurrency and stalls are reported from observed events rather than assumed platform limits.

Optional per-lane UCE endpoints are enabled by default (`--no-uce` disables them). They observe accepted cache requests, first offered/accepted fill packets, complete eight-word ACK masks, aborts and accepted advisory-to-publication intervals on each UCE's local clock. These are separate from HP0: shared RID0 cannot identify I/D demand or prefetch origin. An ACK can be an aborted instruction discard; this endpoint summary does not replace the separate retained fixture's actual-SRAM-write gate. First ACK is not architectural critical-word readiness or dependent load-use latency.

The output binds exact source snapshots, run log, raw/compressed FST, reader build, implementation, selection and selected-event dump. `transactions.json.gz` preserves individual requests, beats and before/after timing. Private RAM holds only losslessly decompressed FST and the reader executable; no full VCD body is exported. A600-second watchdog bounds decoding, and partial/rejected attempts use distinct directories.

Run `python3 -m unittest discover -s testing/rtl/hp0-closed-trace -p test_audit.py -v` for21 host fixtures covering same-ID/multi-ID requests, burst lengths, W-before-AW, reset, corruption, stalls, age deadlines and512-entry saturation. These test the auditor; actual whole-core concurrency/saturation is reported separately.
