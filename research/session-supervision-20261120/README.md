This directory records unexpected loss of a host supervisor during a physical experiment. It preserves the incomplete attempt and the subsequent separately reserved recovery without assigning a kernel or infrastructure root cause. No partial timing from that attempt is accepted.

Session23 attempted the fixed B1-second parse/chase slot. Tool session50244 returned143; the local supervisor, session wrapper and runner processes were absent, the common flock was no longer held, and the session manifest remained nonterminal. The parse log stops after an initial checked-timing row; no guest completion, normal return, CORE/BSG PASS, runner status or second guest exists. That observation cannot distinguish an external supervisor termination from other causes. The original manifest and partial log are retained unchanged and hash-bound in `failure-and-recovery.json`.

Root acquired a new exclusive reservation before any further board action, then power-cycled, waited for readiness and reloaded/verified the intended accepted overlay. The recovery manifest is explicit that this was a new reservation following an ownership gap; it does not claim uninterrupted ownership of the failed session. Recovery completed before the fixed slot was retried. The failed attempt remains in acquisition metadata and is excluded from the sixteen admitted boots.

The retry uses the same source-frozen serialized runner, binaries, transfer, workload order and64/32/4 parameters. Its outer host launch has a separate session/process group, regular-file output, null stdin and an explicit PID so it can be monitored independently of tool-command lifetime. The runner itself still acquires the immutable global flock before staging, keeps it through all recovery/tests and uses the board program lock. This operational guard does not establish the cause of the earlier termination or change the experimental protocol. Retry completion remains pending at this checkpoint.
