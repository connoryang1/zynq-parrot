The candidate needs component and mapped-memory proof before any fullcore or whole-device evaluation.

The selected candidate is the **final integer-context prefetch line**, not another CSR storage mode. `bp_be_top.sv:337–339` declares two1024-bit response copies, while `449–495` uses the16-bank integer backing store. Each bank is64bits×8entries for4contexts×2lines. The leaf accepts one scalar write per cycle (remote port1 wins) and an independent full1024-bit synchronous read. It is1R1W, including legal simultaneous read/write to different addresses; the retained backend's single-port1RW organization cannot be substituted.

Keep the first explicit1024-bit line copy. After the second read, borrow a strengthened held BRAM response for the final line and keep the original line-valid/install counters. Source466–470 issues only the two reads during wait-for-commit/drain; issue_done prevents another until a new miss. Source500–533 and1187–1215 fixes first/final RF write and FE launch timing. Those request, response-valid, drain, line-write and FE cycles must remain identical.

Directly aliasing the current output is invalid. `bsg_mem_1r1w_sync` defaults`latch_last_read_p=0`; its synth source84–95 deliberately sets the idle registered address toX. A new canonical synchronous1R1W leaf must hold the raw response until the next accepted read, independent of later writes. Capture the16 validity bits at the accepted read as well: `bp_be_context_mem:82–88` currently masks from a live bitmap, which could change after later remote seeding. Borrowing that live mask could turn a previously zero saved register into a different value. The strengthened held payload+mask must preserve the old explicit snapshot even for a later same-address write with no read. No new read is allowed before final use unless abort/reset cancels the old lease.

Preserve both scalar write priority and original collision rules. The old leaf's`read_write_same_addr_p=0` asserts on an accepted read and selected same-bank/same-address write. Do not silently legalize a WRITE_FIRST collision, waive the assertion, serialize the two ports or add backpressure. Actual primitive mode/widths/clock/enables and READ_FIRST behavior require mapped inspection/testing. Reset ends the lease and clears valid/token/mask metadata; it need not reset payload bits. Speculative abort with an incoming response/new miss must retain the current nonblocking-assignment priority, including fresh-miss valid clear winning over an old response.

The minimum first gate is a matched **context_mem plus two-line staging shell**, not a full processor or another UCE synthesis. Use exact4context/32register/16lane widths, one selected write from both intents, all1024 payload bits, same original read/valid/install/FE traces, partial validity, drain/FE hold, post-read writes to the held address, writes to other addresses, reset/abort/new-miss turnover, and the original forbidden collision. A simulation-only1024-bit old snapshot must equal every final-line install; a word or valid-mask mutation must fail. Then measure actual production-clock componentFF/LUT/BRAM/controlsets and verify mapped hold/collision behavior with the real inferred primitives. This is at most1,024duplicate declared bits plus a small validity snapshot, not a measured1,024FF or122-slice gain. Enabling a generic extra1024-bit hold latch without accounting for it is not a saving.

No second candidate is selected. Earlier globalCSR command sharing already has a weak source-level bound, and shallow wide LUTRAM can repeat the observed FF-to-LUT tradeoff. Physical/virtual NPC and dirty mirrors require their own temporal proof across save/reseed/launch, and RPC snapshots/two-operand GPR memories retain independent lifetimes/ports. Those are not grounds to delete architectural state or parallel access.
