This figure and CSV compare covered timed target ordinary-miss **counts** for the closed 1 KiB/actor and 32 KiB/actor lookup audits, using the same ELF and FFC model; the 1 KiB case has zero miss opportunities, so no percentage is defined. Validated timed target L1 hits/misses are 5,381/0 and 3,586/1,680, respectively, with 0 and 5,996 actual full-program replacement evictions. The exclusive FIFO ledger uses actual baseline evictions under fixed observed execution, with no execution feedback, speedup or FPGA projection and no equivalence to the FPGA’s four 16 B advisory segments. Reproduce using Python 3.8 with `python3 -m pip install --target /tmp/resource-capacity-plot-deps -r requirements.txt` followed by `PYTHONPATH=/tmp/resource-capacity-plot-deps python3 -B plot_capacity.py`; input hashes, protocol/model metadata and output hashes are retained in `input-hashes-and-metadata.json`, and ring timings are excluded because computation/probe counts differ.
