This packet prepares a narrow inactive-CSR storage substitution for review. It changes no production worktree and authorizes no build, integration, mapping, or deployment. The preview deliberately retains the exact tested masked-output store while a separate unmasked-output counterfactual is being evaluated.

The patch data uses zero-context unified format (`git apply --unidiff-zero`), with exact baseline hashes required before any future application. Apply/reverse checks touched temporary copies only. Zero-context formatting avoids trailing whitespace in blank patch context lines; the source preview bytes are unchanged by that formatting choice.

The BP baseline is `bb575a764c200f07c6f3259a179bdc861dd7593f`; the source-list baseline is TOP `1008854d30e5d923c86c3232fc22af039467d552`. `bp-preview.patch` replaces the packed snapshot array and its valid writes with the exact `0ed6f85da9ca9ee47de25d99bc79d9f43710742014fa4c6f607f06d1f66a4067` single-write module. `top-source-list-preview.patch` adds its sole required explicit source entry. Both patches were applied and reversed on isolated copied files; `source-review.json` binds the snapshots and records byte equality outside six whitelisted edit regions. These are source checks, not integrated RTL correctness evidence.

The full valid vector keeps its existing name and all three control consumers. The only data consumer changes from an indexed packed-array read to the store's asynchronous read. Save address selection remains context-cache victim versus current virtual context; seed address selection remains the committed NPC target. Both writes still use the existing common save-data wire. The exact decoder/wrapper proof `22982102c56242df4afb7f54633d187d68f962c1cd09ffc1a5e0cf98cc135d42` excludes simultaneous save and seed; seed priority in the single write-address mux does not support otherwise independent concurrent writes. NPC, privilege, translation, ASID, physical ownership, context-cache state, rebind/resident qualification, APC routing, ordinary geometry, and CSR packing are unchanged.

Reset clears the valid vector in the module instead of clearing every data bit. Its invalid-data mask preserves the old reset-visible zero output; no architectural consumer may observe uninitialized RAM. All old non-CSR reset/save/seed assignments remain byte-identical. The module's out-of-range read returns zero, whereas the old packed-array out-of-range result is not a defined architectural contract. Promotion therefore requires proving that no out-of-range context is consumed, not asserting raw equivalence for illegal indexing.

The reported masked mapping result adds LUTs despite reducing FFs; this packet makes no area or fit claim. It remains **UNLAUNCHABLE** pending the separately selected module variant, actual mapped evidence, integrated assertions, clean full-core regressions, and whole-device fit. Historical standalone results apply to the exact tested module and envelope, not this uncompiled integration preview.

`consumer-and-gates.md` specifies the raw-invalid-data finding, the narrow assertion contract, source-list requirements, and smallest useful regression ladder. Any future unmasked store must be a distinct source/contract version: replacing the module here without a new proof would invalidate this packet.
