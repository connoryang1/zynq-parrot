This small synthesis probe measures how Vivado 2024.2 maps the exact retained payload and serial-tag RAM geometries. It compares default inference, the documented area attribute, and explicit 1,024-word banks while leaving CPU logic and policies out. It cannot establish full-system fit, routed timing, data correctness or application performance.

The control uses the same independent-clock, two-write-port, read-first template as BP `e10992a3eea3ba2ef6ae3ccb42ff5e8c658286a8`: 20,480 × 64-bit payload and 2,560 × 29-bit tags. All addresses, enables and data are external inputs, and both read outputs are observed. Explicit banks retain the one-cycle selected read; functional equivalence requires valid addresses and no conflicting simultaneous cross-port accesses, as in the existing partitioned store. This source is a synthesis fixture only and is never installed into the processor.
