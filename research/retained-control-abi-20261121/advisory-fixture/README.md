This is a code-only integration fixture for advisory full64B I/D capture with demand copying disabled. It deliberately evicts one checked target from each ordinary L1, submits one direct I replay and one direct D preview, and later checks the complete instruction and data payloads. Crosscompilation and static layout checks pass; no model or target run is included here.

Reproduce with `python3 research/retained-control-abi-20261121/advisory-fixture/build.py`. The manifest binds the source, compiler, linker specs, exact argv, ELF and address markers. The ELF has ten exact 64-byte/16-instruction functions at 4096-byte strides, zero alignment fill, sparse initialized data at the same stride, and control/poll code wholly outside I-set0. The D demand reads words in order 3,4,5,6,7,0,1,2; all sixteen instructions of the I target execute before its return is checked.

Control3 enables I/D advisory lookup/capture and leaves both demand-copy bits off. Before submission the fixture waits for UCE/backend idle and I-lane ready; after submission it requires observed per-lane activity followed by ready/preview-idle/retained-idle, with a 10,000-poll bound and no hint retry. Those snapshots neither prove retention publication nor guarantee global lower-memory drain. Acceptance still requires a closed matching trace demonstrating actual I and D retained backend hits and eight accepted normal-L1 refill beats on each side, followed by the checked completion marker. A dropped hint, missed activity observation or normal-memory fallback is not retained-hit acceptance; this fixture makes no timing, application-capacity or FPGA claim.
