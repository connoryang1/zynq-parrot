| Command | ID | Contract |
| --- | --- | --- |
| `PR_BP_RETAINED_CONTROL` | `0x42505063` | `arg2` mask 0..15; args 3..5 zero. Submits one CSR5c2 clear/write, with no added `fence.i` or implicit polling. |
| `PR_BP_RETAINED_STATUS` | `0x42505064` | `arg2` writable pointer to a full 64-bit snapshot; args 3..5 zero. Copy occurs after preemption is enabled. |

Both commands require `CAP_SYS_ADMIN` and exactly one possible CPU. Argument errors precede privilege checks, which precede CPU and hardware checks. The capability read precedes every accepted write under preemption disable; an absent CSR or missing capability bit returns `ENODEV` without a write or user copy. Existing RISC-V `traps.c` routes kernel illegal instructions through `fixup_exception()`; the actual `asm-extable.h` type-3 handler sets the independent error register to `-EFAULT`, zeros the value register and resumes after the CSR read. The helper translates either failure to `ENODEV`. The crosscompiled micro-object uses these actual exception-table/register macros and checks distinct encoded registers; it is not a configured kernel translation unit or a hardware trap test.

CSR5c2 controls are I lookup bit 0, D lookup bit 1, D demand-refill copy bit 2 and I demand-refill copy bit 3. A demand-copy bit requires its lookup bit, and controls for a configured zero-capacity lane read back zero. Status bit 63 is capability; bits 3:0 are actual effective controls, bits 9:8 are I/D busy, bits 11:10 are I/D wrap-seen, bits 31:16 and 47:32 are the actual I/D full64B line counts, bits 55:48 are log2 sets, bit 56 identifies full64B payloads and bit 57 identifies conservative same-set mutation invalidation. Other bits are reserved. This reports physical payload slots, not guaranteed unique useful lines; same-set kills, pending cancellation and wrap sweeps can reduce retention.

The busy snapshot covers ordinary UCE/client metadata, queues, completions and retained backend ownership. It does **not** prove lower-L2/AXI/DRAM drain, all CPU buffers empty or a globally atomic interval. The interface is global state with no ownership lock or per-task save/restore; privileged experiments must serialize writers. Submission and every caller poll belong inside any future measured whole-execution boundary. The new ABI does not add a normal-L1I invalidation, unlike the preserved legacy 0027 control.

The standalone guest commands, only after an independently built matching kernel is available, are `./retained_store_probe.elf absent` or `./retained_store_probe.elf present`. The present probe reads capability before any valid write, rejects missing/truncated/reserved descriptor bits, derives effective masks from reported capacities, checks all 16 masks, and bounds each actual status/readback poll to 4,096 calls. It checks malformed arguments and bad user pointers, uses a real fork/credential drop to require `EPERM` for child controls/status, verifies the parent controls survived denied writes, and resets controls to zero. A parent-only error cleanup also submits zero and bounds polling; a cleanup failure cannot print PASS. Process death or an unavailable kernel is not a cleanup guarantee and still requires the separately coordinated recovery procedure.

The 20 new host tests run the actual patch C decision branches with only CSR/credential/preemption/user-copy primitives interposed. They cover absent/read-before-write, all masks and zero/single/non-power-of-two geometries, full 64-bit copying, invalid arguments, privilege/SMP rejection before hardware access, copy faults after preemption enable, real fork, geometry drift, bounded busy timeout, denied mutation, privilege bypass and reset failure. Actual-source patch tests prove exact forward/reverse behavior, duplicate refusal, the 0027 dependency and 0028 independence without writing canonical sources; the copied 0027 `kernel/sys.c` also exactly matches the retained accepted c7 kernel source.
