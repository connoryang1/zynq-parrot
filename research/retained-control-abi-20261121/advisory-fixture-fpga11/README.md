This is the offline FPGA software variant of the accepted first-touch advisory08 mechanism fixture. It removes the simulation debug-mode exit and packages without the NBF debug flag, while retaining the exact full64B instruction/data layout checks. No board upload, execution, routed fit or application performance is claimed.

`build.py` crosscompiles the same maintained C source with `BP_FPGA_PROGRAM=1` and checks every linked code/data word, sparse zero fill, hot-page bounds and submission/demand/completion labels. The disassembly contains no `dcsr`, `dpc` or `dret`. `manifest.json` and `package.json` bind source, tools, ELF and nondebug NBF; gzip copies losslessly preserve the exact packaged bytes.

The ELF hashes to `ab9219e91bb0976353648199b3c6b7eacbba032012c53f1d8015c8c5fd2a64ab`, and the NBF to `37a63ac75c9a95546ba757213b1778ee92a72370ce7c20da68f35397b5831afa`. A later physical run requires a separately accepted exact overlay/package, the entire-session common reservation and maintained serialized board runner. Checked physical completion alone will not prove retained hits; the separate simulation08/full-core scaled gates establish only their own measured mechanism.
