| User index | GP0 byte offset | Event |
|---|---|---|
| 7 | `0x3c` | Accepted backend response hit that UCE accepts for restore: valid/ready/hit, enabled, no clear or demand mutation |
| 8 | `0x40` | Successful backend publication, `PUBLISHED && DONE` |
| 9 | `0x44` | State22 retained-fill accepted normal-L1 data beats with actual slow-write enables; I additionally excludes instantaneous/latched abort |

The I lane samples the positive core clock, D the inverted/negative clock, matching the actual UCE/backend domains. A word counts one accepted packet beat, not the number of asserted SRAM banks. Published outputs are registered lane-local completion pulses, counted when sampled in that lane. All six 16-bit fields saturate at65,535; saturation is a lower bound and cannot support subtraction into an exact activity delta. Only external AXI reset clears them. BP/tag reset suppresses increments while retaining prior counts, independently of control/retention clears. Sequential host reads are not an atomic live snapshot; these counters count global/speculative/control activity, not retired work or workload-specific benefit.
