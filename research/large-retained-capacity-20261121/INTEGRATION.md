Accepted source branches and FPGA packages remain intact.

Global supervisor/machine CSR `0x5c2` controls I lookup/prefetch capture (bit0), D lookup/prefetch capture (bit1), D ordinary-refill copying (bit2), and I ordinary-refill copying (bit3). Copying requires its side enabled. Every retired command clears both retained tag stores; the registered clear spans both clock phases. Accepted lookups, insertions and memory replies drain across clear/disable. The CSR is absent with the feature disabled and denies user-mode access. [The real wrapper/decoder gates](../large-retained-control-20261121) cover both feature states and retirement-bank routing.

Status bit63 reports capability; bits3:0 report sanitized controls; bits9:8 report I/D UCE/backend busy, **not** prefix-controller or lower-L2/AXI quiescence. Bits11:10 record epoch wraps since the last command, bits31:16 and47:32 count actual I/D slots, bits55:48 report log2 retained sets, bit56 indicates full64B payload and bit57 indicates conservative same-set invalidation. Stores invalidate all retained D lines in the affected retained set; epoch wrap triggers a tag sweep. Slots therefore do not guarantee useful unique capacity, and lookup, capture drops, clear sweeps and collateral invalidation must be charged in later results.
