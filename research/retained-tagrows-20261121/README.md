For at most eight ways, tags occupy synchronous true-dual-port set rows with disjoint I and D row-address partitions. A single row read compares the bounded way set in parallel; the 64-bit serial payload RAM and all eight words per slot remain unchanged. At 1280 lines per side / 256 sets / PA34 / epoch8, each row has five 29-bit tag records: 145 bits × 512 rows. Logical tag bits equal the old balanced geometry; actual BRAM packing, frequency and fit are not established by these declarations. Larger maximum way counts select the existing serial lookup/insertion branches and original per-slot tag layout at elaboration. No new macro, runtime policy or Tcl carrier is introduced.

Each tag retains its own epoch and valid bit. A matching tag outranks the first available entry; otherwise the first valid physical empty slot wins, then RR if replacement is enabled. As before, every successful publication advances RR, including refresh and empty allocation, and wraps at that set's actual last physical slot. Whole-row read/modify/write first invalidates only the selected tag, before payload overwrite. Publication changes that tag only after all eight payload writes. Clear, epoch wrap, same-set invalidation and insertion cancellation take priority over writes/publication; accepted lookup/insert ownership and stalled-hit revocation retain the original contracts. Partial ways are masked, unequal partitions retain their exact payload bases, and disabled sides do not access RAM.
