This prototype separates the retained I/D memories into private owning-clock single-read/write-port arrays while preserving their existing behavior. It addresses a reproducible Vivado failure in the previous area-decomposed shared dual-port implementation without reducing payload capacity or changing policy. The closed component tests establish functional and cycle equivalence; actual inference, whole-core correctness, and routed fit require separate gates.

The isolated branch starts at TOP `cc01fdf32575ad32d0eca838e45abe5d99799ee8` / BP `20c74bfb1633c6580945c047828546d723384def`. Backend checkpoint `d766d42cdf04ee43ca1e915fb9da06f5cc117dde` changes only physical RAM declarations/accesses and explanatory comments. Both tag and payload arrays retain `ram_style="block", ram_decomp="area"`. Each lane has its own enabled, synchronous read-first process, preserving read latency. The D lane subtracts the static I base from the unchanged logical global address; existing partition-bound assertions remain. Zero-capacity lanes have unused minimum-size declarations. No RAM reset, new macro, banking policy, capacity change, or ordinary L1 change is introduced.

`closed-component001/manifest.json` binds the source, commands, models, raw closed FSTs and compact snapshots. The original 93/131 gate passes unmodified under both clock patterns. The twelve-geometry equivalence matrix passes all 24 runs and 23,401,321 settled evaluations against original BP `e10992a3eea3ba2ef6ae3ccb42ff5e8c658286a8`, including all client controls, valid-hit full 512-bit data, and enabled logical RAM access timing/address/write data. The FSM, policy and assertion tail is byte-identical to that original. A deliberate one-bit corruption of the reference read data is rejected by the comparison with exit 1 and no completion markers.

The runner and reproduction details are in [the gate documentation](../../testing/rtl/retained-private-sp/README.md). The matrix covers zero, one-sided, balanced 64–1536 and partial unequal 93/131 capacities using 64 retained sets and a two-bit epoch, opposite-phase and different-period clocks, full payloads, replacement, high addresses, overlapping writes, backpressure, invalidation, cancellation, clear and epoch wrap. Raw FSTs and compiled objects remain under the externally bound artifact paths, outside Git. No Vivado, full-core build or board action was run for this checkpoint, and the component results do not establish improved packing, a fitted maximum, or application benefit.

The subsequent separately admitted clean full-core gate is closed in [FULL_RESULTS.md](FULL_RESULTS.md) and `closed-full001/manifest.json`. It passes the unchanged integrity/cold08 programs, strict full-line restoration and actual counter checks, source ingestion, and generated static16KiB L2 checks. The arrays have logical single-owning-clock 1RW interfaces; this does not guarantee that inferred primitives use only one physical port. Full-system routed fit and physical validation remain pending.
