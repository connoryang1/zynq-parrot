This directory binds the completed routed PYNQ-Z2 fit for the demand-admission retention prototype. The prototype reuses the existing instruction advisory payload and refill stream, adding no retained data capacity or speculative reads. Route and package validation pass; physical capability and application performance remain separate gates.

The frozen build is top `7edf64d1`, BlackParrot `2958cd72`, static `e_bp_unicore_zynqparrot_prefetch_cfg`, Vivado 2024.2 and eight workers, with the accepted default dimensions and clocks. The maintained builder produced package `07a48584...` containing bitstream `f744228b...`. Setup WNS is +0.039 ns, TNS zero; hold WHS is +0.011 ns, THS zero. All routable nets are routed with no overlaps. The exact final reports and routed checkpoint are retained durably and hash-bound in `manifest.json`.

Placement consumes 51,358 LUTs, 25,859 registers, 94.5 BRAM tiles, 11 DSPs and 13,295 of 13,300 slices. Five free slices and narrow timing margin leave little room for further changes. The report's 42 no-clock pins, 76 unconstrained internal endpoints and TIMING-2/4/14/17 categories also occur in the accepted timing reference. This records closure of the user-specified constraints, not proof that every CDC path is constrained. VCU128 catalog warnings concern another board definition; vectorless power warnings provide no measured power claim. All DRC/methodology reports remain available for review.
