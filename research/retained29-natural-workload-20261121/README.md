Every disabled arm uses mask0. The only advisory source accepted by this variant is literal `none`, reported in every configuration/source row. It never writes a prefix/data table or triggers an advisory replay; it disables inherited task preview mode in parent and child. Advisory-only policies are therefore explicit **null-source controls**, not prefetch-effectiveness experiments. Before allocation, the program validates actual capability/full64B/coarse-invalidation flags, reserved bits, immutable slot counts/set log2 and selected-lane availability. It requires fresh global mode0 entry rather than overwriting an unknown active owner. The global policy is exclusive experiment state; no privileged concurrent writer is supported. Every cell begins its WHOLE timer and parent/children resource snapshot, disables task preview, bounds existing D-replay and I-prefix controller settling, submits its actual0/enabled mask and checks real readback plus UCE/client/backend busy. Each status-poll loop is bounded at4,096 calls. The selected mask is active **before allocation** and stays active through allocation, fork, setup, warmup, timed work, verification, child exit/reap and both frees.

The maintained setup `fence.i` calls remain in both processes/arms; they can invalidate instruction retention during setup, and their cost is charged. The terminal handshake keeps child verification outside the steady request timer while including it in WHOLE. After all work is checked/reaped/freed, the parent disables task preview, submits global0, settles controllers then UCE/backend, validates reset readback and unchanged unsaturated I/D advisory counters, and samples ending resources before WHOLE ends. Every result/leg/whole/control/resource/source row is printed only with global0. Both arms pay their actual control/observer costs. Program admission and configuration/report output are outside paired cells; complete invocation costs require a separate full-command measurement.

The D-controller status uses raw `SYS_prctl(0x4250505d)` to preserve its full64bits, including completed-reply bit63; the int-return `prctl()` wrapper would truncate them. Negative signed data status is not automatically a syscall error. D-controller sequence/queue/held-entry/downstream-slot/completed bits are settled before the I-prefix and5c2 busy checks, so previously queued data-follow-I work cannot be mistaken for an idle return path. Unsaturated accepted/filtered/trigger/drop counters must remain unchanged inside each cell. Initial inherited activity may finish before the first cell and is not represented as new cell activity. These checks are controller/UCE/backend boundaries, **not lower-L2/AXI/DRAM or global memory-drain evidence**.
